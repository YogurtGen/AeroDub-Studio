# Local music engine 0.3.0

This machine's standalone Python 3.12.14 runtime lives in `ai-runtime`. It is copied into `dist/win-unpacked/resources/ai-runtime`; Python is launched directly with argument arrays, without a shell or system Python. `src/ai_worker.py` is unpacked from ASAR. Processing jobs run in a separate cancellable process. Audio remains on this computer and models are loaded from explicit local directories; the application has no download or remote transcription action.

## Pinned processing

- Demucs 4.0.1 with the official HTDemucs FT vocal specialist `04573f0d-f3cf25b2.th`, the vocal-weighted member of the official FT bag. Source map: https://github.com/facebookresearch/demucs/blob/main/demucs/remote/files.txt and https://github.com/facebookresearch/demucs/blob/main/demucs/remote/htdemucs_ft.yaml . Model SHA256: `f3cf25b222c4eed7cd49dd8b2c9597d50c18bd154090f7b919cfa5f93cf22c49`. Safe PyTorch weights-only loading verifies this full hash and the expected class. Seven-second windows with 25% overlap and one shift limit GPU memory use. The instrumental is the input minus estimated vocals; both stems share the same safety scaling and are saved as 44.1kHz stereo PCM24.
- faster-whisper 1.2.1 / CTranslate2 4.6.0 using https://huggingface.co/Systran/faster-whisper-large-v3 at revision `edaa852ec7e145841d8ffdb056a99866b5f0a478`. `model.bin` SHA256: `69f74147e3334731bc3a76048724833325d2ec74642fb52620eda87352e3d4f1`. CUDA uses int8_float16; CPU uses int8. Beam size 5, word timestamps, no voice activity filter and no previous-text conditioning. Input is isolated vocals, read by SoundFile, mixed to mono and resampled to 16kHz before inference. This also avoids the PyAV 19 decoder signature mismatch. Low-confidence lines receive a review note; low-energy regions are excluded.
- The transcript selector supports auto/en/id/zh-CN/ja/ko. English/Indonesian/Mandarin/Japanese/Korean labels match Settings. Mandarin maps to Whisper's `zh`. The line editor validates finite bounded timing, text length and unique IDs. Unchanged lines preserve measured word times; edited lines interpolate words across the edited interval and show that timing is estimated.
- Two synchronized Web Audio buffer sources route instruments and guide/selected singing take through separate gains, one compressor and the real spectrum analyser. Lyrics follow the output audio clock. Singing starts with a cancellable three-second countdown, captures through MediaRecorder and trims the capture lead before padding to the song duration. Retakes remain available rather than replacing earlier captures. Export uses the selected voice and instrumental, with matching saved gains and a limiter.

## Preparing a build machine

Use a standalone relocatable Windows Python 3.12 installation at `ai-runtime` with `python.exe`, matching DLLs, standard library and its license. Install packages only into that runtime. Install torch/torchaudio 2.6.0 cu124 from https://download.pytorch.org/whl/cu124, then the remaining pinned packages in `docs/ai-requirements-lock.txt`. This workspace's runtime is prepared and GPU inference has passed. Do not replace the user's global Python installation.

Run `ai-runtime/python.exe src/ai_worker.py prepare --runtime ai-runtime` on an online build machine to retrieve the pinned official model files and write their manifest. Keep the upstream model license texts and model card in `ai-runtime/models`. Offline builds reuse these files. `npm run build:win` creates a directory build because the complete local inference runtime and models are several GB; this version does not create an installer. The surrounding directory must accompany the EXE.

## Verification fixtures

`tests/music-ui.js` uses `test-output/music/source.mp3`: an original Windows SAPI spoken phrase mixed with a synthetic 220Hz backing track, 10.57 seconds long. Phrase: “This is my song. We are singing in the sunlight. Let the blue sky carry our voices.” No downloaded song is used. The actual separated vocal transcript matched the phrase with 17 word timestamps. The fake microphone source is `test-output/media/mic.wav`, created by `npm test`. Native file dialogs are stubbed to these files; inference, capture, processing and exports are real. Each run uses a separate profile and deletes only its synthetic project through the normal Recycle Bin action.

`npm test` verifies trim/padding, captured voice audibility, actual doubled voice gain, bounded lyrics, original word-time retention, five-language edits, protection of source/stems and cancelled-export preservation. `npm run test:music-ui` verifies the full UI workflow. Set `AERODUB_TEST_EXE` to the packaged EXE to run the same test against the directory build. `npm run test:package` checks source/ASAR integrity and bundled model hashes.

The controlled spoken/music fixture establishes functional inference and timing, not lyric accuracy across commercial music. Physical microphone latency, long-song drift, CPU-only hardware and a clean machine have not been tested. Singing words and separation can still need correction.

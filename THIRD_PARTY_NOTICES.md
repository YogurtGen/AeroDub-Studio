# Bundled third-party software

Offline lyric readings in 0.5.2 add pypinyin 0.55.0 (MIT, https://github.com/mozillazg/python-pinyin), pykakasi 2.3.0 (GPL-3.0-or-later, https://github.com/miurahr/pykakasi), korean-romanizer 0.28.0 (GPL v3, https://github.com/osori/korean-romanizer), fugashi 1.5.2 (MIT with bundled MeCab BSD-3-Clause notices, https://github.com/polm/fugashi), and unidic-lite 1.0.8 (UniDic dictionary and its own license texts, https://github.com/polm/unidic-lite). Japanese pronunciation uses the local UniDic dictionary before conversion to Latin letters. Supporting packages are jaconv 0.5.0 (MIT), Deprecated 3.0.0 (MIT), and wrapt 2.5.1 (BSD-style). Their complete LICENSE/COPYING files remain in each distribution's metadata; UniDic's dictionary COPYING is also retained under resources/ai-runtime/Lib/site-packages/unidic_lite/dicdir. Python package modules, dictionary data and bundled native libraries are included in resources/ai-runtime. No reading service or runtime dictionary download is used. The exact versions are pinned in docs/ai-requirements-lock.txt and the runtime's requirements-lock.txt.

AeroDub Studio's application source is licensed under GPL-3.0-or-later; see LICENSE. This local development build uses the following runtimes. All app source files and the package lock are available in the workspace.

- Electron 44.7.2: MIT. https://github.com/electron/electron . Electron's LICENSE and LICENSES.chromium.html are included by electron-builder in the installed application directory. Chromium and Node components carry their own notices there.
- ffmpeg-static 5.3.0: GPL-3.0-or-later package. https://github.com/eugeneware/ffmpeg-static . The Windows executable identifies itself as FFmpeg 6.1.1 essentials, built by Gyan with --enable-gpl and --enable-version3. Its GPL text and build/source metadata are bundled beside ffmpeg.exe in app.asar.unpacked/node_modules/ffmpeg-static/. Upstream build: https://www.gyan.dev/ffmpeg/builds/ . Source revision reported by the bundled README: https://github.com/FFmpeg/FFmpeg/commit/e38092ef93 . Includes GPL codecs such as x264/x265. It is not an LGPL-only build.
- ffprobe-static 3.1.0: MIT JavaScript wrapper. https://github.com/joshwnj/ffprobe-static . Its bundled Windows executable is FFprobe 4.0.2, an older Zeranoe GPL v3 build with --enable-gpl and --enable-version3. Wrapper LICENSE/README and FFmpeg GPL text are included. Original source tag: https://github.com/FFmpeg/FFmpeg/tree/n4.0.2 . Before public redistribution, obtain the complete corresponding source for this exact executable and linked libraries, or replace it with a reproducibly built current probe.
- ffmpeg-static runtime helpers carry their own package licenses in node_modules. npm audit --omit=dev reported zero runtime advisories on 2026-10-14.

Universal voice monitoring uses @soundtouchjs/audio-worklet 2.1.1, with its bundled @soundtouchjs/core, @soundtouchjs/worklet-base and @soundtouchjs/interpolation-strategy-lanczos implementations at 2.1.1. Author/project: Steve 'Cutter' Blades and SoundTouchJS contributors, https://github.com/cutterbl/SoundTouchJS . The npm packages declare MPL-2.0. The complete unmodified processor JavaScript and full license text are included in src/renderer/vendor/soundtouch-processor.js and SOUNDTOUCH-LICENSE.txt inside app.asar. This source remains available under MPL-2.0; the surrounding AeroDub source uses its own GPL license. The processor runs locally in Chromium's AudioWorklet. Final take effects use the bundled FFmpeg filters.

The 0.3.0 folder build also includes Python 3.12.14 (PSF license and bundled component notices in resources/ai-runtime/LICENSE.txt), PyTorch 2.6.0+cu124 and torchaudio 2.6.0+cu124 (BSD-style licenses), Demucs 4.0.1 (MIT), faster-whisper 1.2.1 (MIT), CTranslate2 4.6.0 (MIT), NumPy 1.26.4 and SoundFile 0.13.1. Python package distribution metadata, LICENSE/COPYING/NOTICE files and included native-library notices are retained under resources/ai-runtime/Lib/site-packages. CUDA/cuDNN components in the PyTorch GPU wheel also carry NVIDIA terms; review the exact binary distribution conditions before publishing a release. The full dependency version inventory is docs/ai-requirements-lock.txt and resources/ai-runtime/requirements-lock.txt.

The model files are the official Demucs HTDemucs fine-tuned vocal specialist 04573f0d, distributed from Meta's dl.fbaipublicfiles.com/demucs repository, and the Systran CTranslate2 conversion of OpenAI Whisper large-v3, pinned to Hugging Face revision edaa852ec7e145841d8ffdb056a99866b5f0a478. Demucs' upstream project declares MIT; Whisper code and weights and the conversion model card declare MIT. Model licenses are included as resources/ai-runtime/models/DEMUCS-LICENSE.txt and WHISPER-LICENSE.txt, alongside the converted model card. Exact sources and SHA256 hashes are recorded in docs/music-engine.md and resources/ai-runtime/models/manifest.json. Sources: https://github.com/facebookresearch/demucs , https://github.com/openai/whisper , https://huggingface.co/Systran/faster-whisper-large-v3 .

Smart dub adds sherpa-onnx and sherpa-onnx-core 1.13.8 (Apache-2.0, wheel license texts retained), the sherpa-onnx conversion of pyannote segmentation-3.0 (MIT, Copyright CNRS; LICENSE retained with the converted model), and WeSpeaker ResNet34-LM speaker embeddings. The official WeSpeaker model card declares CC BY 4.0; attribution/model card and license text are included in resources/ai-runtime/models/speakers/WESPEAKER-MODEL-CARD.md and WESPEAKER-LICENSE.txt. Model authors: the WeSpeaker project, https://huggingface.co/Wespeaker/wespeaker-voxceleb-resnet34-LM and https://github.com/wenet-e2e/wespeaker . The ONNX model with metadata is supplied by k2-fsa/sherpa-onnx's speaker-recongition-models release; the conversion/metadata process is documented at https://github.com/k2-fsa/sherpa-onnx/blob/master/scripts/wespeaker/run.sh . Model weights are not retrained or modified by AeroDub. Source URLs and exact hashes are in docs/smart-dub.md and the bundled manifest. Diarization runs locally on CPU and does not identify people by name.

No external icon packs or fonts are included. The app icon is generated with the built-in imagegen tool for this project; provenance and prompt are recorded in docs/icon-direction.md. The UI uses the locally installed Segoe UI font, original mountain SVG and procedural CSS highlights/bubbles. The approved soft portal sound is original procedural synthesis generated by scripts/make-portal-sfx.py, without sampled audio. Browser microphone noise suppression and FFmpeg afftdn provide capture cleanup; music stem separation uses the bundled model.

This folder is an unsigned local development build. Public distribution requires completing the corresponding-source and third-party notice review for the exact bundled media and GPU binaries.

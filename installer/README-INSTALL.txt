AERODUB STUDIO 0.5.2 - WINDOWS X64

Recommended: download and run AeroDubStudio-Setup-0.5.2-x64.exe.
Choose the installation folder and optional desktop shortcut before the
download begins. This single EXE automatically downloads the full audio
engine and AI models from the matching GitHub Release, checks SHA256 hashes,
then installs the application and models in your chosen folder. Keep your
internet connection active during setup. You can open AeroDub from the
finish page.
After installation, the application works offline. No separate Python,
Node.js or API key is required.

Offline alternative: download AeroDubStudio-OfflineSetup-0.5.2-x64.exe
and ALL matching .bin files. Keep them in the same folder and run the
OfflineSetup EXE. These files are the complete installer; do not unpack
the .bin files manually. Copy the entire set to another computer to install
without downloading again.

The online EXE needs the matching release assets to be published at:
https://github.com/YogurtGen/AeroDub-Studio/releases/tag/v0.5.2-preview.1

Setup installs per user on Windows 10/11 x64 and creates a Start menu entry
and an uninstaller. Projects and recordings use AeroDub's separate user-data
folder. Keep personal projects outside the application installation folder.

Allow space for both the downloaded package in the Windows temporary folder
and the installed application. A failed download can be retried in the same
wizard; already completed and verified files are reused until it closes.

SHA256SUMS.txt lists the application installer and data-slice checksums.
The preview is unsigned. See RELEASE_NOTES.md for testing and limitations.
